Kebijakan Privasi ANDALAN

Berlaku sejak 2 Oktober 2026

ANDALAN ("aplikasi") adalah aplikasi kasir untuk Android yang bekerja tanpa internet. Kebijakan ini menjelaskan data apa yang diproses aplikasi dan bagaimana data itu dilindungi.

1. Data toko tersimpan di HP Anda

Semua data yang Anda masukkan — produk, stok, transaksi, pelanggan, kasbon, shift, pengguna, dan pengaturan toko — disimpan hanya di penyimpanan HP Anda. Data tersebut tidak pernah dikirim ke server kami, dan kami tidak dapat melihatnya.

2. Pembelian ANDALAN Pro

Pembelian ANDALAN Pro diproses sepenuhnya oleh Google Play. Kami hanya menerima status pembelian (aktif, tertunda, dibatalkan) dari Google Play, bukan data kartu atau pembayaran Anda. Pengelolaan data pembayaran tunduk pada Kebijakan Privasi Google.

3. Pembaruan aplikasi

Saat terhubung ke internet, aplikasi dapat memeriksa dan mengunduh pembaruan perbaikan melalui layanan Shorebird. Permintaan itu hanya berisi informasi teknis (versi aplikasi, platform, dan jenis prosesor HP), tanpa data toko apa pun.

4. Backup

File backup dibuat atas perintah Anda atau terjadwal, lalu disimpan di folder yang Anda pilih. Backup dapat dilindungi kata sandi. Kami tidak memiliki akses ke file backup Anda.

5. Laporan masalah

Bila Anda menekan "Laporkan masalah", aplikasi menyiapkan teks berisi versi aplikasi, merek/model HP, versi Android, sisa ruang penyimpanan, dan catatan error teknis. Teks ini tidak berisi data transaksi dan hanya terkirim bila Anda sendiri membagikannya lewat aplikasi lain (mis. WhatsApp atau email).

6. Izin yang digunakan

  • Bluetooth — menghubungkan printer struk.
  • Kamera — memindai barcode produk dan mengambil foto produk.
  • Notifikasi — pengingat stok dan backup.
  • Biometrik — membuka kunci aplikasi dengan sidik jari (opsional).
  • Penyimpanan — menyimpan dan membuka file backup, laporan, dan label.
  • Internet — pembelian Google Play, pembaruan aplikasi, dan membuka tautan bantuan.

7. Tanpa iklan dan analitik

Aplikasi tidak menampilkan iklan, tidak memakai pelacak iklan, dan tidak mengirim data analitik.

8. Penghapusan data

Karena data ada di HP Anda, Anda dapat menghapus seluruhnya dengan menghapus aplikasi atau memilih "Hapus data" di pengaturan Android. Hapus juga file backup yang pernah Anda simpan bila diperlukan.

9. Anak-anak

Aplikasi ditujukan untuk pelaku usaha dewasa dan tidak ditujukan untuk anak di bawah 18 tahun.

10. Perubahan kebijakan

Kebijakan ini dapat diperbarui. Versi terbaru selalu tersedia di halaman ini, dengan tanggal berlaku di bagian atas.
